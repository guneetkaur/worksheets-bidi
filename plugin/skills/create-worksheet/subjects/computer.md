## Computer-specific question types

- **Fill in the blanks** — "A computer is a ______ machine."
- **MCQ** — Which is an input device? (Keyboard / Monitor / Printer / Speaker)
- **Match** — device ↔ function, device ↔ input-or-output
- **Label the diagram** — parts of a computer (monitor, CPU, keyboard, mouse)
- **True / False** — "The CPU is called the brain of the computer."
- **Identify from picture** — input vs output devices
- **Short answer** — "Why is the keyboard called an input device?"

## Common Class III topics

- Parts of a computer (monitor, CPU, keyboard, mouse, speaker, printer, scanner)
- Input vs output devices
- Hardware vs software
- Uses of a computer (at home, school, bank, hospital, office)
- Good computer habits (posture, eye care, power off, don't eat near it)
- Types of computers (desktop, laptop, tablet, smartphone)
- Basic MS Paint (tools: pencil, brush, eraser, bucket, shapes)
- Basic MS Word (typing, saving, font size)
