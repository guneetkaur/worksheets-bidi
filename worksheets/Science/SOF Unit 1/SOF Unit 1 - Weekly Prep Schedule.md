## DAILY PRACTICE TEMPLATE (Use Weekly)

**Each day, allocate time as follows:**

```
WARMUP (5 min)
  ↓
LEARN/REVIEW (20–25 min)
  ↓
PRACTICE (15–20 min)
  ↓
REVIEW & DISCUSS (5–10 min)
```

### Sample Day Structure

**Monday (Example: Plants topic)**
- **Warmup (5 min):** Recall: "Name 3 trees, 3 shrubs, 1 herb"
- **Learn (25 min):** Read Section 1.1–1.3 from Topic Deep-Dive
- **Practice (15 min):** Answer L1 worksheet questions 1–3 (on plants)
- **Review (5 min):** Discuss answers, correct mistakes, clarify doubts

## WEAK AREA TARGETING SYSTEM

### When Ambar Gets a Question Wrong:

1. **Record in Mistake Journal**
   - Date, Topic, Question #, Type of mistake (Recall / Understanding / Reasoning)
   - Correct answer + Why Ambar got it wrong

2. **Identify Pattern**
   - Is it the same topic repeatedly? (e.g., always confused on climber vs creeper)
   - Is it a reasoning issue? (e.g., can't apply concepts)

3. **Re-teach + Re-practice**
   - Use Topic Deep-Dive to re-read that section
   - Do 5 similar practice questions on that topic
   - Quiz Ambar verbally next day to reinforce

4. **Track Progress**
   - Same question type in next week's practice should show improvement
   - Log in Mistake Journal: "Revisited on [date] — Score: [%]"
